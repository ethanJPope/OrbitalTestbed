# Orbital Testbed

A unity project where you can visualize orbits using the terms used by the professionals making orbits for real satellites.

## Why I made this project
I made this project because in school I am participating in a "compition" where we create satellite orbits using the softaware the real engineers use. So to learn all of the aspects of the I created this project I did lots of resaarch,  that I probably wouldn't do if I wasn't making this project, so I could implement all of the parts to be as accurate as possible compared to STK (the professional software I am acctually using).

## Features
- A side window with all of the values to cahnge the orbit
    - Apogee
    - Perigee
    - Incination
    - RAAN
    - Argument of Perigee
- Hovering over the names of these values will show a small text giving the definition of these values
- Right Click and drag to rotate around the Earth
- Scrollbar to zoom in and out
- A sphere representing a satellite follwing the orbit
